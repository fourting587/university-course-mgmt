# 实训材料说明

本目录是《信息化系统开发与应用》实训的交付材料，基于学院提供的《实训报告模板.docx》生成。

## 交付清单

| 文件 | 说明 |
|------|------|
| `信息化系统开发与应用实训报告-刘中天-20231026120.docx` | 实训报告（39 页，约 7500 汉字，含封面、目录、页码、8 章正文、3 个附录、6 张运行截图） |
| `功能模块图.png` | 系统功能模块图（报告图 4-2） |

| `测试用例.xlsx` | 30 条系统测试用例（含模块、前置条件、操作、预期结果、结论） |

## 报告结构

1. 系统开发背景（背景、目标、技术栈）
2. 实验环境及配置介绍（环境表、安装步骤、验证结果）
3. 系统需求（角色用例、功能需求、非功能需求、业务规则）
4. 系统概要设计（部署架构、功能模块、接口、界面、流程）
5. 系统 E-R 图设计（基础数据 E-R、教学数据 E-R、关系说明）
6. 系统数据库设计（设计原则、16 张表清单、核心表结构、外键策略、初始化数据）
7. 系统功能实现（登录权限、考勤、表现、实验、作业、成绩、基础数据、前后端分离、测试）
8. 项目总结及收获（过程、收获、问题与解决、不足与改进）
- 附录 A 数据库脚本说明
- 附录 B 主要接口清单
- 附录 C 运行说明
- 附录 D 核心建表 SQL
- 参考文献

## 使用说明

1. 用 Word 打开报告，目录已生成；如修改正文导致页码变化，右键目录 → 更新域 → 更新整个目录。
2. 报告 7.11 节已包含 6 张运行截图（登录、工作台、考勤、成绩、学生管理、操作日志），由 `docs/capture_screenshots.js` 自动抓取。
3. 报告中的图 4-1、4-2、5-1、5-2 已按 A4 宽度排版，可直接打印。
4. 如需 PDF，Word 中“另存为 → PDF”即可。

## 重新生成

```bash
python docs/make_diagrams.py     # 生成图（SVG -> HTML）
# 用 Chrome 截图 docs/src/*.html 得到 docs/*.png
python docs/trim_diagrams.py     # 裁白边、去背景
python docs/make_report.py       # 基于模板生成 docx
python docs/make_testcases.py    # 生成测试用例 xlsx
```

> 生成报告后需在 Word 中更新一次目录域（脚本已设置打开时自动更新）。
